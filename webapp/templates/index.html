How to Read This Map

What am I looking at?

This interactive map shows how a machine learning model organizes microscopy experiments based on the visual characteristics of the cells.

Each point represents one experimental well. Wells that appear close together contain cells with similar visual patterns according to the model, while wells farther apart have more different learned representations.

The model compares each well using a numerical summary of the images it analyzed. This map is a simplified visualization that helps explore patterns in the model's understanding of the wells it analyzed.

What does each point represent?

Each point represents a single well from a Cell Painting experiment.

A physical plate holds many individual wells arranged in a grid. Each well is one independent mini-experiment containing cells treated with a specific compound. Every point on the map corresponds to exactly one well.

Each well can hold a different treatment (color) — one well, zoomed in, shows multiple images, each with many cells.

Each well contains many cells and microscopy images. The model processes those images and combines them into a single numerical representation called an embedding — a compact "fingerprint" that captures the visual patterns of the cells in that well.

In this visualization, each well is represented by a 384-dimensional embedding that has been projected into two dimensions for visualization.

Learn more: Introduction to embeddings (TensorFlow)

What does distance mean?

The distance between points represents similarity in the model's learned representation.

  • Nearby points → the model considers the cell images to have similar visual patterns.
  • Distant points → the model considers the cell images to have different visual patterns.

This similarity reflects phenotypic similarity (i.e., similarity in observable cellular appearance) and should not be interpreted as proof that two compounds have the same biological mechanism of action.

For example, two compounds may appear close together because they cause similar morphological changes, even if they act through different biological pathways.

How should I interpret clusters?

When multiple points form a visible group, it means the model's learned representation of those wells is similar. In other words, the model observed similar visual patterns in the images corresponding to those wells.

A cluster may suggest that the wells in it share a similar morphological response, which can be a useful starting point for a hypothesis. On its own, it does not prove that those wells share the same biological mechanism.

What affects the map?

A well's position reflects the visual patterns the model learned from the cell images. These patterns can include biological differences such as changes in cell shape, organelle organization, and other morphological responses caused by compounds.

Embeddings can also capture experimental variation: differences between plates, experiments, imaging sessions, or other technical conditions can influence where a well lands on the map, alongside genuine morphological differences.

For this reason, patterns on the map are best read as model-learned similarities rather than guaranteed biological relationships. Switching the "Color by" option to Plate is a quick way to check whether a given pattern lines up with plate identity rather than treatment.

What do the axes mean?

The original embeddings contain 384 dimensions, which cannot be directly visualized. UMAP (Uniform Manifold Approximation and Projection) is a dimensionality reduction method that compresses high-dimensional data into two dimensions while attempting to preserve local relationships.

The UMAP axes themselves do not represent specific biological features. The meaningful information is:

  • which points are close together
  • which groups form clusters
  • and how samples relate to each other.

Learn more: UMAP documentation

Why don't the closest points on the map always match the neighbor list?

The "Neighborhood Summary" and "Representative Neighbors" panels are computed directly in the full, 384-dimensional embedding space, not from the 2D positions shown on the map.

UMAP is built to preserve local structure, but compressing 384 dimensions down to 2 can visually change some relationships; a point may appear visually close to another point on the map without being its true nearest neighbor, and a true neighbor may appear farther away. The dotted lines on the map show this directly: they connect a selected point to its true nearest neighbors in the full embedding space. Note that this is expected behavior for a 2D projection and is not an error.

Two points close together in the full embedding space can land far apart after compressing to 2D — and an unrelated point can land right next to the selected one instead.

What does the attention map show?

The attention map highlights which regions of the microscopy image the model relied on most when forming its representation of that well. Brighter regions received more attention and darker regions contributed less.

Attention is not a direct explanation of biology. It shows what the model focused on, not necessarily what is biologically important. A highly attended region may or may not correspond to a meaningful cellular structure, and an important structure may not always receive high attention. For example, because the model processes images as small patches, attention maps may show a faint grid or increased attention near patch boundaries. This is a visualization artifact of Vision Transformers and should not be interpreted as a biologically meaningful pattern.

About the Project

Project goal What is Cell Painting? Why analyze cell morphology? How did the model learn? Why is this interesting? What could this be used for?

Project goal

This project tests whether a self-supervised vision model can learn useful representations of Cell Painting images without using compound or mechanism-of-action labels during training. This visualization lets you explore what the model discovered from the images alone and examine whether those patterns correspond to known biological effects

What is Cell Painting?

Cell Painting is a high-content microscopy assay that uses fluorescent stains to visualize multiple structures inside cells.

Cells are stained to highlight features including:

  • nucleus
  • mitochondria
  • endoplasmic reticulum
  • RNA
  • cytoskeletal and membrane structures.

A standard digital image has three channels: red, green, and blue (RGB). Cell Painting works similarly, but captures five separate grayscale channels instead of three. Each channel corresponds to a different fluorescent stain and highlights a different aspect of the cell.

By capturing many cellular features at once, Cell Painting provides a detailed view of how compounds change cell morphology.

Learn more: Broad Institute Cell Painting overview

Why analyze cell morphology?

Changes in a cell's appearance can reveal how a compound affects cellular processes. Compounds may alter features such as:

  • cell shape
  • organelle organization
  • nuclear morphology
  • texture
  • and overall cellular state.

These observable changes are called phenotypes. By measuring these phenotypes, Cell Painting provides a way to compare how different compounds affect cells.

How did the model learn?

This project uses a self-supervised AI model, meaning the model learns patterns directly from the images without being given labels about what those images represent. During training, the model is not told which drug treated each sample or what biological process that drug affects. Instead, it learns to identify visual patterns that consistently appear across cell images.

After training, the model's learned patterns can be compared with known biology to see whether it discovered meaningful relationships between cellular appearance and drug effects.

Why is this approach interesting?

Large microscopy datasets contain enormous amounts of information, but manually labeling every image with biological annotations is expensive and incomplete. Self-supervised learning provides a way to discover patterns without requiring predefined labels, reducing the need for costly manual annotation and allowing researchers to explore much larger datasets than would be practical through traditional approaches.

What could this be used for?

If a model like this reliably captures phenotypic signal without labeled training data, it could support several practical uses in early-stage drug discovery:

  • Hit prioritization: identifying new compounds that produce similar cellular effects to compounds with known mechanisms.
  • Drug repurposing: finding existing drugs whose cellular profiles suggest potential new uses.
  • Mechanism discovery: generating hypotheses about how an uncharacterized compound works by comparing it to better-understood compounds.
  • Prioritizing follow-up experiments: helping researchers decide which compounds are most worth testing with more targeted and expensive assays.

This project is a proof of concept for the first step in that pipeline: testing whether self-supervised learning can extract pharmacologically meaningful structure from Cell Painting images. It is not a deployed drug discovery tool, and the current model has important limitations described in the Technical Details section.

Training data

The model was trained on a subset of the JUMP Cell Painting dataset consisting of compound perturbation microscopy experiments — wells treated with a chemical compound rather than a genetic perturbation. Training used no compound or mechanism-of-action labels: the goal was to learn morphological patterns directly from the unlabeled images themselves.

Model architecture

The embedding model is a Vision Transformer (ViT) trained using the DINO self-supervised learning framework. A Vision Transformer divides images into smaller regions and learns relationships between those regions to build a numerical representation, or embedding, of the image. The model outputs a 384-dimensional embedding representing learned visual features.

Learn more: Vision Transformer paper (Google Research)

How is the model trained?

DINO trains with a self-distillation objective using two networks: a "student" network and a slower-moving "teacher" network (an exponential moving average of the student's weights). Both networks are shown different augmented views of the same image. The student learns to match the teacher's output distribution across these views using a cross-entropy loss, while the teacher's outputs are centered and sharpened to prevent the model from collapsing to the same output for every image.

Because both sides of this comparison come from the same unlabeled image, no compound or MoA label is ever involved in this training signal. See DINO (arXiv) for the full method.

From images to embeddings

Each well is imaged at multiple sites, producing several microscopy images per well. The model processes each image and produces a numerical embedding for it. These per-image embeddings are then combined into a single well-level embedding, which is what gets postprocessed, compared for similarity, and ultimately plotted on the map.

Embeddings and similarity

An embedding is a numerical representation produced by the model. Instead of comparing images directly pixel-by-pixel, embeddings allow the model to compare images based on learned features. For this project:

  • each well is represented by a 384-dimensional vector
  • embeddings summarize learned morphological patterns
  • similarity is measured using cosine similarity, which compares the orientation of two embedding vectors rather than their absolute scale.

Embedding processing

Before visualization, embeddings are processed to make them more comparable across plates and experiments. Processing includes:

  • Median absolute deviation (MAD) normalization: reduces variation introduced by differences between plates and imaging batches
  • Sphering/whitening transformations: rebalances the embedding space so no single dimension or learned pattern dominates comparisons
  • Normalization before similarity calculations: puts every embedding on the same scale so similarity scores are comparable across wells.

Together, these steps reduce unwanted technical variation and prepare embeddings for consistent similarity comparisons.

UMAP visualization

Because the embeddings exist in a 384-dimensional space, they cannot be directly displayed. UMAP creates a two (or three) dimensional representation that preserves local relationships between samples as much as possible.

The final map is therefore an interactive window into the model's learned embedding space rather than a direct biological coordinate system.

Evaluation

The learned embeddings are evaluated by checking whether biologically related samples are enriched near each other in the embedding space more than would be expected by chance.

This includes comparing neighborhood similarity between replicate wells, agreement between a well's nearest neighbors and its annotated mechanism of action, and the amount of variation explained by technical factors such as plate identity. These are research diagnostics, not evidence of a validated drug discovery model — see Limitations below.

Channel importance

Cell Painting images have 5 fluorescent channels, each highlighting different cell structures: Mito (mitochondria), AGP (actin cytoskeleton, Golgi apparatus, and plasma membrane), RNA (nucleolus/RNA), ER (endoplasmic reticulum), and DNA (nucleus). When you select a well, the right sidebar's "Channel Importance" bars estimate how much each of these 5 channels contributed to that specific well's embedding.

This is computed by channel ablation: for the well's representative image, the model embeds the original 5-channel image to get a baseline embedding, then re-embeds 5 variants with one channel at a time zeroed out. Each channel's raw importance is 1 − cosine similarity between the baseline embedding and that channel's ablated embedding. The more the embedding shifts when a channel is removed, the more the model relied on it. The 5 raw scores are then normalized to percentages that sum to 100%, so the bars are directly comparable to one another.

This matters because it's a per-well, data-driven check on which stains actually drove the model's representation of that image, rather than relying only on what's pharmacologically documented about a compound. Where a MoA has a well-established target organelle (shown alongside the bars when one exists), it's worth comparing the two: rough agreement is a small piece of evidence the model picked up on a biologically meaningful signal, while disagreement doesn't necessarily mean the model is wrong — it may be relying on a real but less-obvious morphological cue instead.

Limitations

This is a proof-of-concept model trained on a subset of available Cell Painting data, It is not a universal morphology foundation model. The following are the key limitations of the model:

  • The compound library behind this map is a single fixed reference set (~300 compounds, one plate design) imaged across multiple replicate plates, so results should not be read as a general test of the model's chemistry coverage.
  • The learned representation still shows a measurable plate/batch effect: which plate a well came from is more predictable from the embedding than one might expect from morphology alone.
  • Agreement between a well's neighbors and its annotated MoA is well above random chance, but modest in absolute terms. Treat clustering patterns as suggestive, not diagnostic.
  • The UMAP layout is for visualization only. Similarity and neighbor calculations are performed in the full, high-dimensional embedding space and can disagree with what looks closest on the map (see "How to Read This Map").
